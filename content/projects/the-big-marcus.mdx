#### The problem

My personal trainer needed a client management system to manage his clients and sessions efficiently with an intiuitive web interface. B wtefore this project, he was using WhatsApp to manage appointments - which was inefficient and caused conflicts in scheduling.

#### The approach

The approach was to build a web interface that allowed the trainer to manage clients and appointments efficiently. The interface was built using Next.js and TypeScript, with Supabase for the backend and Motion.js for animations.

#### The result

The result was a web interface that allowed the trainer to manage clients and appointments efficiently. The interface was intuitive and easy to use, and the management system allowed the trainer to view and manage clients, appointments, and calendar events in real-time.

The client can now log in, view their appointments, and sync their calendar. The trainer can manage clients and appointments through the web interface.
