#### The problem

My client was looking for a web application design for a Design & Web Resource Marketplace. He wanted a clean, modern design that would be easy to use and navigate focusing on a eco-friendly and sustainable approach.

#### The approach

I worked closely with my client to understand their requirements and design a clean, modern web application design in Figma. The design was inspired by nature and sustainability which inspired the design choices made for the project such as the green theme, which also goes along with the name of the project.

#### The result

A fully functional web application design for a Design & Web Resource Marketplace.
